# Decode

Decode is a responsive web application designed to help users learn coding concepts through quizzes. The application features a user-friendly interface and tracks user progress.

## Features

1. **Home Page**: 
   - Branding and a call-to-action button to "Start Learning".
   
2. **Quiz Module**: 
   - Multiple-choice questions covering topics such as Data Structures and Algorithms (DSA), Python, Java, Object-Oriented Programming (OOP), and more.
   - Displays the user's score at the end of the quiz.

3. **Progress Tracker**: 
   - Tracks user scores and completed quizzes locally.

4. **User Interface**: 
   - Built with HTML, CSS (or Bootstrap/Tailwind), and JavaScript.
   - Designed to be minimal, modern, and student-friendly.
   - Fully responsive for both desktop and mobile devices.

5. **Optional Features**: 
   - Leaderboard functionality or a mock test mode.

## Setup Instructions

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd CodeFlow
   ```

3. Open `index.html` in your web browser to start using the application.

## Usage Guidelines

- Click on the "Start Learning" button on the home page to begin the quiz.
- Answer the multiple-choice questions presented.
- At the end of the quiz, your score will be displayed.
- Track your progress through the quizzes locally.
